# Task 01 · 应用骨架与进程通信

## 目标
搭建 Electron 主进程与渲染进程的基础工程结构，集成 React + Ant Design UI 框架，建立统一的 IPC 服务注册与调用约定，为后续模块提供稳定可靠的应用底座。

## 关键输出
- 初始化主进程、预加载脚本、渲染进程目录结构与打包配置。
- 集成 Ant Design 全局样式、主题配置与基础布局组件。
- 设计统一的 IPC 服务注册、类型声明与渲染层调用封装，提供示例服务。
- 完成基础页面布局：顶部搜索栏、左侧筛选面板、结果列表与详情面板。

## 验收标准
- 启动应用后呈现符合 PRD 描述的主界面布局，Ant Design 组件样式正常。
- 渲染进程可通过封装 API 调用主进程示例服务，并获得返回结果。
- IPC 管理模块具备统一注册、冲突检测、移除等能力，满足后续扩展需求。
